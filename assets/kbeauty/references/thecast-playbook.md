# 더캐스트 콘텐츠 플레이북 (TheCast content playbook)

더캐스트(TheCast)는 라이브 커머스·다시보기·피드·숏폼·브랜드 스토리·구독을 제공하는 프리미엄 K-뷰티 플랫폼이다. 콘텐츠는 "발견 → 시연 → 구매" 흐름을 따른다.

## 1. 라이브 커머스 대본 구조
1. **오프닝 (0~2분)**: 인사 + 오늘의 제품 한 줄 요약 + 시청자 혜택 예고.
2. **제품 시연 (핵심)**: 손등/얼굴에 직접 발라 텍스처·발림성·흡수·향을 보여준다. "보이시나요" 식으로 시각 정보를 구체화.
3. **효능·성분 설명**: 핵심 성분 1~2개 + 적합 피부. 의학적 주장 금지.
4. **리얼 후기·FAQ**: 실제 사용 팁, 질문 예상 답변, 오해 바로잡기.
5. **혜택·구매 유도**: 할인·구성·기간 한정 등 구체 안내.
6. **마무리**: 다음 라이브 예고 + 인사.

실시간 질문 대응: "피부 타입별 추천", "사용 순서", "재구매 문의", "배송/교환" 답변을 미리 준비한다.

## 2. 숏폼 스크립트 (15~60초)
- **3초 훅**: "지성 피부라면 이거 하나로 끝나요" 등 타깃을 명시.
- **본문**: 핵심 효능 1가지만 강조 + 텍스처/결과 시각 시연.
- **CTA**: "프로필 링크에서 확인" 또는 "라이브에서 만나요".

## 3. 피드·상품 설명
- 구조: 브랜드 스토리 → 제품 포인트(성분+효능) → 사용법 → 추천 대상 → 구매 정보.
- 브랜드 스토리는 "왜 이 성분/원료를 썼는가"를 감성적으로 전달한다.

## 4. 구독(맞춤형) 소개
- 피부 타입 진단 → 맞춤 큐레이션 강조 → 배송 주기·해지 조건 명확 안내.
- "다음 결제일부터 자동 결제 중단" 등 해지 조건을 정확히 설명한다.

## 5. 언어별 톤
- **한국어**: 친근+전문. "피부가 숨 쉬는 느낌", "쫀쫀한 제형" 같은 감각 표현 활용.
- **영어**: 간결+신뢰. "plumping", "soothing", "glass skin", "dewy finish" 등 K-뷰티 보편 표현 활용.

## 6. 컴플라이언스 체크리스트
- 치료·질환 효능 주장 금지. "완화·관리·도움" 표현.
- 가격·할인·재고·배송 정보는 최신 데이터로 확인 후 기재.
- 해외 고객 대상 시 통관·배송·반품 정책을 함께 안내.
