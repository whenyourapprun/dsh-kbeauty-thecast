# 피부 타입 상세 가이드 (Skin-type reference)

추천 전에 피부 타입을 확정하고, 민감도·현재 고민을 함께 기록한다. 타입과 민감도는 별개 축이다.

## 1. 타입 판별 질문
- 세안 후 1시간 뒤 얼굴 상태? (당김=건성, 번들거림=지성, T존만=복합성, 균형=중성)
- 특정 성분·제품에 붉어지거나 따가운 적? (민감도)
- 현재 주요 고민? (수분/모공/피지/미백/탄력/트러블/붉음)

## 2. 타입별 추천 방향

### 건성 (Dry)
- 부족한 것: 유분·수분·장벽.
- 추천: 세라마이드, 판테놀, 히알루론산, 스쿠알란, 달팽이 점액, 프로폴리스.
- 제형: 크림·오일·밀크 클렌저. 세정력 강한 폼·알코올 많은 토너는 피함.
- 주의: 과도한 각질제거 금지.

### 지성 (Oily)
- 부족한 것: 수분-유분 균형, 피지 관리.
- 추천: 나이아신아마이드, BHA, 녹차, 클레이, 가벼운 히알루론산.
- 제형: 젤·로션·가벼운 수분크림. "유분기 없는" 제형 강조.
- 주의: 유분을 완전히 제거하려는 과세정은 오히려 피지 과다 유발.

### 복합성 (Combination)
- 추천: 부위별 맞춤 — T존엔 가벼운 제형, 볼엔 보습 강화.
- 핵심 성분: 나이아신아마이드(균형), 히알루론산(수분).

### 중성 (Normal)
- 추천: 기본 루틴 유지, SPF 필수, 항산화 성분으로 예방.

### 민감성 (Sensitive)
- 추천: 시카/병풀, 판테놀, 알란토인, 무향·저자극·EWG 그린 등급.
- 피함: 알코올, 합성향, 레티놀·AHA/BHA 고농도.
- 주의: 신제품은 팔 안쪽 패치 테스트 후 얼굴 사용.

## 3. 고민별 핵심 성분 매핑
| 고민 | 우선 성분 |
|---|---|
| 수분 부족 | 히알루론산, 세라마이드, 판테놀 |
| 피지·모공 | 나이아신아마이드, BHA |
| 미백·톤 | 비타민C, 나이아신아마이드, 트라넥삼산 |
| 탄력·주름 | 레티놀, 펩타이드, 인삼 |
| 트러블·붉음 | 시카, 녹차, 판테놀, BHA(저농도) |
| 장벽 손상 | 세라마이드, 판테놀, 스쿠알란 |

## 4. 표현 규칙
- "○○ 타입에 적합", "○○ 고민에 도움" 식으로 쓴다.
- "치료·완치·여드름 치료" 같은 의학적 표현은 쓰지 않는다.
- 자극 가능 성분은 반드시 주의를 병기하고 패치 테스트를 권장한다.
