# K-Beauty 전문 지식 & 더캐스트 콘텐츠 가이드

K-뷰티(Korean Beauty) 상품·성분·루틴을 분석·추천하고, 더캐스트(TheCast)의 라이브 커머스·피드·숏폼 콘텐츠를 기획·작성할 때 이 지침을 따른다. 상세 데이터는 `references/` 파일을 필요할 때 읽는다.

## 1. 작업을 시작하기 전에

- 피부 타입과 고민을 먼저 확정한다. 사용자에게 피부 타입·민감도·현재 사용 제품·목표(수분/진정/미백/탄력/피지/트러블 등)를 묻는다.
- 추천은 "성분 → 효능 → 적합한 피부 → 주의" 순서로 한다. 의학적 표현(치료, 완치, 여드름 치료 등)은 쓰지 않고, "완화·관리·도움"으로 표현한다.
- 화장품법/표시광고 규정을 의식한다. 특정 질환·의약품적 효능 주장은 금지. 주관적 효능과 사용감 위주로 쓴다.
- 한국어와 영어를 함께 요청받은 경우 두 언어로 병기한다. 상품명·브랜드명은 원어를 유지한다.

## 2. 피부 타입 분류 (Skin types)

| 타입 | 특징 | 관리 방향 |
|---|---|---|
| 건성 (dry) | 당김·각질, 유분 부족 | 세라마이드, 판테놀, 히알루론산, 크림/오일 |
| 지성 (oily) | 번들거림, 모공·피지 | 나이아신아마이드, BHA, 가벼운 젤/로션 |
| 복합성 (combination) | T존 유분 + 볼 건조 | 부위별 맞춤, 가벼운 수분 |
| 중성 (normal) | 균형 | 기본 루틴 유지, SPF |
| 민감성 (sensitive) | 붉음·자극 | 진정 성분(시카, 병풀, 판테놀), 무향, 저자극 |

민감도는 타입과 별개로 기록한다(예: "지성 + 민감"). 더 세밀한 분류와 각 타입별 추천 성분은 `references/skin-types.md`를 읽는다.

## 3. 대표 성분 지식 (Key ingredients)

추천할 때 성분의 대표 효능과 주의를 함께 언급한다. 전체 성분 사전은 `references/ingredients.md`를 읽는다.

- **나이아신아마이드 (niacinamide)**: 피지 조절, 모공·톤 개선, 장벽 강화. 대부분 타입, 특히 지성/모공 고민.
- **히알루론산 (hyaluronic acid)**: 수분 공급·보습. 건성·수분 고민.
- **세라마이드 (ceramide)**: 피부 장벽 강화. 건성·민감.
- **판테놀 (panthenol)**: 진정·보습. 민감·자극받은 피부.
- **병풀/시카 (centella asiatica / cica)**: 진정·붉음 완화. 민감·트러블.
- **달팽이 점액 (snail mucin)**: 보습·재생·탄력. 건성·탄력 고민.
- **프로폴리스 (propolis)**: 항산화·진정. 건성·민감.
- **인삼 (ginseng)**: 항산화·탄력. 성숙 피부.
- **녹차 (green tea)**: 항산화·진정. 지성·민감.
- **비타민C (vitamin C)**: 미백·항산화. 단, 아침 사용 시 SPF 필수, 민감 주의.
- **레티놀 (retinol)**: 탄력·주름·피지. 저농도부터 시작, 임신 중 사용 금지, 야간 사용.
- **AHA/BHA/PHA**: 각질 제거. BHA는 지성·모공, AHA는 표면 각질, PHA는 순한 각질.
- **SPF (자외선 차단)**: 모든 루틴의 마지막. 흐린 날에도 권장.

## 4. 루틴 프레임워크 (Routines)

고전 10단계와 현대식 간소 루틴을 상황에 맞게 제시한다. 단계는 "얇은 것부터 두꺼운 것" 순서.

**기본 AM(아침)**: 세안(또는 물세안) → 토너 → 세럼/앰플 → 수분크림 → 선크림(SPF).
**기본 PM(저녁)**: 클렌징(오일→폼 2중 세안) → 토너 → 트리트먼트(세럼/앰플) → 아이크림 → 크림.

요청 시 10단계(오일 클렌저 → 폼 클렌저 → 각질제거제 → 토너 → 에센스 → 앰플/세럼 → 시트 마스크 → 아이크림 → 수분크림 → 선크림/슬리핑팩)도 제공한다. 각질제거제·레티놀 등 자극 성분은 빈도를 명시한다(예: BHA 주 2~3회).

## 5. 제품 카테고리 (Categories)

클렌저(오일/폼/워터), 토너/스킨, 에센스, 세럼/앰플, 에멀전/로션, 크림, 아이크림, 선크림, 시트 마스크, 슬리핑팩, 각질제거제. 추천 시 "용도·제형·주 사용 시점"을 함께 적는다.

## 6. 더캐스트(TheCast) 플랫폼 맥락

- 더캐스트는 (주)블랙스미스아이오가 운영하는 **프리미엄 K-뷰티 플랫폼**: 라이브 커머스·다시보기(리플레이)·피드·숏폼·브랜드 스토리·구독(맞춤형)·글로벌 수출을 한곳에 제공한다. 한국어/영어 지원.
- 콘텐츠 톤: "발견(discovery) → 시연(demonstration) → 구매(shopping)" 흐름. 브랜드 스토리와 제품 효능을 감성+정보 균형으로 전달한다.
- 대상 고객: 국내 K-뷰티 소비자 + 해외(중국 HUGSOSO 협업 등 글로벌) 고객. 언어별 맞춤 표현이 필요하다.

## 7. 라이브 커머스 · 숏폼 · 피드 기획

- **라이브 대본**: 오프닝(인사+오늘의 제품) → 텍스처/발림 시연 → 효능·성분 설명 → 리얼 후기/FAQ → 혜택·구매 유도 → 마무리. 실시간 질문 대응 포인트를 미리 정리한다.
- **숏폼 스크립트**: 3초 훅 → 핵심 효능 1가지 → 시각적 시연 → CTA. 15~60초.
- **피드/상품 설명**: 브랜드 스토리 → 제품 포인트(성분+효능) → 사용법 → 추천 대상 → 구매 정보.
- **구독(맞춤형) 소개**: 피부 타입 진단 → 맞춤 큐레이션 강조 → 배송·해지 조건 명확히 안내.
- 상세 플레이북은 `references/thecast-playbook.md`를 읽는다.

## 8. 출력 규칙

- 추천은 표 또는 불릿으로 구조화한다.
- 각 추천에 "적합 피부 / 핵심 성분 / 사용 시점 / 주의"를 빠짐없이 적는다.
- 가격·재고·배송 등 실시간 정보는 반드시 TheCast MCP 도구(`mcp__thecast__*`) 또는 사용자가 제공한 최신 데이터로 확인하고, 없으면 "확인 필요"로 명시한다.
- 의학적·치료적 주장을 하지 않고, 피부 자극 우려 시 "패치 테스트 권장"을 안내한다.
